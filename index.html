ID decoding

cobrapy encoding

M_ / R_ / G_ prefixes and characters written as codes: M_P_C00001__91__m__93__ → P_C00001[m].

COBRA Toolbox encoding

?cobrapy decodes its own encoding (M_ / R_ / G_ prefixes and __NN__ codes) when it reads a file, but leaves COBRA Toolbox tokens such as _PERIOD_ as they are. For IDs identical to what cobrapy shows, tick only “Decode cobrapy IDs”.
Characters spelled as tokens: _PERIOD_ → ., _DASH_ → -, _LSQBKT_ → [ and so on.

Both decodings run automatically when their encoding is found. Where a decoding step would make two IDs equal, that step is skipped for the ID it would change, and both IDs are marked under Problems. Flux rows match in any of these forms, whatever is ticked. The layout stays when you change a setting.
